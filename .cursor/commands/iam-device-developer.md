# iam-device-developer workflow

Run the **iam-device-developer** workflow for the Jira story ID provided by the user.

1. Read and follow the workflow in `.cursor/skills/iam-device-developer/SKILL.md`.
2. The user will provide the story ID in this chat (e.g. IAM-5851). If not provided, ask for it.
3. Execute all steps in order. Pause for user approval at the indicated steps (plan approval, post-review/lint approval, commit approval).
4. Do not skip approval gates.
5. **Skip git push**; Present the **final tabulated summary checklist** from the skill at the end.
