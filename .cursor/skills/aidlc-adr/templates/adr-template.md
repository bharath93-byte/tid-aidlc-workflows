Replace every `<...>` placeholder; do not leave any in the final draft.

status: proposed
authors: [<team or author>]
date: <today's date>
related_doc: <path to vision.md>
---

## Notes on filling the template

- The `Index` anchor slug MUST match the GitHub-style markdown heading
  anchor for the ADR title (lowercase, spaces to hyphens, punctuation
  stripped) so the links resolve.
- If this ADR document is later revised, add a `> **Revision note:** ...`
  blockquote immediately under the affected ADR's `**Status:**` line in
  `{EPIC_DIR}/adr.md` rather than deleting the original text, so the
  decision history stays visible.
- Do not omit `Alternatives Considered` even for a decision with only one
  realistic option — state that no credible alternative was identified and
  why.
